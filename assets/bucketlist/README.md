# BUCKETLIST portfolio screenshots

The game-plan, Phoenix courts, team-selection, and showcase-stats screenshots come from the matching PNG files under `docs/` in `adoblake/making-bucketlist` at commit `844567563aa6d6fc9e900533d96c862624687ae2`.

The project's README and `public/site-config.js` identify the public app as https://adoblake.github.io/bucketlist/ and the canonical source repository as https://github.com/adoblake/bucketlist.

The screenshots show a demonstration profile, game, and statistics. Court discovery, game rosters, and statistics are a browser-local prototype; the separate authenticated community service provides shared groups and chat.

The court-directory capture shows geographically positioned court pins over a neutral grid because street tiles were unavailable in that capture. The image caption states this limitation. Showcase statistics represent a fictional player, not verified performance.
