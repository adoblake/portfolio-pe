# Current 2DAY portfolio screens

The active portfolio images were captured from `adoblake/2DAY-APP` commit `34f3ca4548fee49a7186c867d689dea1763113c9`, release 12.1.0, on November 3, 2026:

- `2day-home-v12-1.png`: Home with the Rising Bars identity and maintenance program.
- `2day-current-day.png`: current daily meal view.
- `2day-current-calendar.png`: outside-calendar flow.
- `2day-current-guidance.png`: program guidance review.

Captures use staged, browser-local demonstration progress, not real user data. The app ran locally with its original Big Shoulders Display and DM Sans fonts, supplied from the corresponding Fontsource npm packages because the app server does not bundle the fonts. No application UI was changed for the screenshots. No SMS or email provider was configured or contacted.

The public destination remains https://adoblake.github.io/2DAY-APP/. Google and Outlook links hand off to editable provider events; users review and save them there. Optional provider-backed messaging requires a separate Node server and credentials, so the portfolio does not claim messaging works on GitHub Pages.

The Home asset has a release-specific filename so browsers do not reuse the previous preview. Older assets remain archived but are no longer used in the active card, focus section, or case-study dialog. Future project refreshes should capture the latest source and update these references without changing the shared portfolio design.
